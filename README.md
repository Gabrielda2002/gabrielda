# Portfolio — Gabriel Duarte

Portafolio de Gabriel Duarte, desarrollador web full stack, con estética de consola retro de doble pantalla.

## Comandos

| Comando        | Acción                                     |
| -------------- | ------------------------------------------ |
| `pnpm dev`     | Servidor de desarrollo en `localhost:4321` |
| `pnpm build`   | Compila el sitio a `./dist`                |
| `pnpm preview` | Previsualiza la build localmente           |
| `pnpm check`   | Chequeo de tipos (`astro check`)           |
| `pnpm format`  | Formatea el código con Prettier            |
